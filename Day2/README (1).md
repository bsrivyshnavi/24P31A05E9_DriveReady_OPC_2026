# Day 2 – Bakery Chatbot with Memory

## Overview
An improved AI chatbot for Sweet Crumbs Home Bakery that answers customer questions using system prompts and conversation history.

## Features
- Answers questions about menu items, prices and bakery policies.
- Remembers recent customer details and orders.
- Calculates total prices using Python functions.
- Logs function calls using decorators.
- Handles API rate-limit and connection errors.

## Technologies Used
Python, Google Colab, OpenAI Python SDK and LLM API.

## Concepts Covered
- System, user and assistant message roles
- Prompt engineering and few-shot prompting
- JSON and Python dictionaries
- Conversation history and context trimming
- Functions, type hints, decorators and exception handling

## How to Run
1. Run the Day 1 API setup in Google Colab.
2. Run the Day 2 code (`task.py`).
3. Enter bakery-related questions.
4. Type `exit`, `bye` or `quit` to stop.

Keep API keys private and do not upload them to GitHub.

## Learning Outcome
Understand how to build a context-aware chatbot with structured prompts, conversation memory and basic error handling.
